# 来源及使用规则

1. [zhwiki / 陳奕迅](https://zh.wikipedia.org/wiki/陳奕迅)：唱片列表、演唱会及相关条目。API `action=parse` 获取结构化 HTML 和修订 ID。
2. [zhwiki / FEAR_AND_DREAMS](https://zh.wikipedia.org/wiki/FEAR_AND_DREAMS)：巡演场次、不同主歌单、逐日 Encore。原表歧义不得强行拆分。
3. [doriscullen/EasonKG](https://github.com/doriscullen/EasonKG)：网易云、百度百科衍生候选事实；抽取方法和版本详见 `easonkg.json`。

内容署名、Wikipedia 页面贡献者及历史版本见原条目“查看历史”；若再利用受 CC BY-SA 约束的原创编排及描述，遵守对应许可。资料更新须更新 source revision，不要无来源覆盖数据。
